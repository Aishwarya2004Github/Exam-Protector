# Exam Proctoring System

## Overview
The Exam Proctoring System is an application designed to monitor and supervise online examinations. It ensures fair examination practices by tracking user behavior and detecting potential violations during exams.

The system can be used by educational institutions, training centers, or organizations conducting remote assessments.

---

## Features
- User authentication (Student / Admin)
- Real-time exam monitoring
- Face detection to ensure candidate presence
- Detection of multiple faces
- Tab switching / window change detection
- Exam session logging
- Automatic flagging of suspicious activities
- Admin dashboard for exam review
- Secure exam environment

---

## Technologies Used
- Frontend: HTML, CSS, JavaScript  
- Backend: Python / Node.js (update as applicable)  
- Database: MySQL / MongoDB / SQLite  
- Computer Vision: OpenCV  
- Other Tools: WebRTC / Flask / Express (if used)

---

## System Architecture
1. User logs in and starts the exam
2. Proctoring module activates (camera + activity monitoring)
3. User behavior is analyzed continuously
4. Violations are recorded and flagged
5. Admin reviews reports after the exam
